# In-context associative interference

Code, figures, and analysis summaries for the
write-up *In-context associative interference: a zero-parameter onset law
and its cue-format generality* (Julia Steinberg, September 2026; MATS 12.0
application, Neel Nanda stream).

**Question.** Does the signal-versus-interference argument that sets the
capacity of an associative memory transfer, quantitatively, to attention?
Give a model $N$ paired associates in context, cue one, and measure at the
retrieval heads the key contrast $\Delta$ and its spread $\sigma^2$. The
prediction with nothing fitted is that the cued item loses half its
attention mass at

$$\ln N^* = \beta\Delta - \tfrac12\beta^2\sigma^2 .$$

Tested on Qwen3-0.6B / 1.7B / 4B-Base, five cue formats, $N \in \{2,\dots,256\}$
at fixed context length.

## Layout

| Path | What |
|---|---|
| `src/` | Harness: `items.py` (stimulus), `capture.py` (forward pass, QK-score capture), `channels.py` ($A_{\text{att}}$, $A_{\text{logit}}$, $\Delta$, $\sigma^2$), `analysis.py` (head selection, crossovers, P1/P2), `lexicons.py`. |
| `scripts/` | `run_grid.py` (main sweep), `run_*.sh` (controls, cue formats, probe captures), `analyze_grid.py`, `control_*.py`, `leak_diagnostic.py`, `p2_residual_decomp.py` (exact interference sum vs Gaussian), `fit_probes.py` (control 2), `fig_*.py`, `raw_examples.py`. |
| `figures/` | All figures in the write-up. |
| `runs/analysis/` | Every number quoted in the write-up: per-model summaries, `p2_residual_*` (residual decomposition), `probe_*` (control 2), `raw_examples.md`. |

The raw activation grids (`runs/grid/`, `runs/probe/`; ~1.7 GB) are not
included. They are regenerated by the scripts below from the stated seeds.

## Reproduce

```bash
pip install -r requirements.txt          # transformers 4.57.6 matters: hidden_states[-1] is post-final-norm
export PY=python                          # or the interpreter of your choice
bash download_ladder.sh                   # Qwen3-0.6B/1.7B/4B-Base from the Hub
$PY scripts/run_grid.py --model Qwen/Qwen3-0.6B-Base   # main sweep (repeat per model)
bash scripts/run_arms2.sh; bash scripts/run_arms3.sh   # cue-format and reverse-cue runs
bash scripts/run_controls.sh; bash scripts/run_probe.sh
$PY scripts/analyze_grid.py               # -> runs/analysis/<model>.txt
$PY scripts/p2_residual_decomp.py         # -> runs/analysis/p2_residual_*
$PY scripts/fit_probes.py                 # -> runs/analysis/probe_*
$PY scripts/fig_p2_crossover.py; $PY scripts/fig_frames.py; $PY scripts/raw_examples.py
```

Runs were done on Apple silicon (MPS) in fp32 for 0.6B/1.7B and bf16 for 4B.
